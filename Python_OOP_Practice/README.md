# Python OOP Practice

A collection of 10 hands-on Python tasks covering the core concepts of Object-Oriented Programming: classes, objects, encapsulation, inheritance, polymorphism, and abstraction. Each task is a single, self-contained file that can be run on its own.
## Concepts Covered

| Concept | Description |
|---------|-------------|
| Classes and Objects | Defining classes, creating objects, attributes and methods |
| Encapsulation | Private data, controlled access through methods |
| Getters and Setters | Reading and updating private data safely, with validation |
| Inheritance | Reusing and extending behaviour of parent classes |
| Polymorphism | Same method name, different behaviour in different classes |
| Abstraction | Hiding implementation details behind abstract classes |
