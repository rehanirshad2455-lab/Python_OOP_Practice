# OOP Practice

A collection of Object-Oriented Programming tasks focused on **classes**, **objects**, and **encapsulation**. Each task is kept in its own folder so the progress is easy to follow.

## Concepts Covered

- **Classes and Objects**: defining classes, creating objects, attributes and methods
- **Encapsulation**: private data, getters/setters, controlled access to state
- **Constructors**: initializing objects properly
- **Data validation**: protecting object state from invalid values

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/oop-practice.git
   cd oop-practice
   ```
2. Open any task folder and run the file, for example:
   ```bash
   # Python
   python task01_xxx/main.py

   # Java
   javac Main.java && java Main

   # C++
   g++ main.cpp -o main && ./main
   ```
